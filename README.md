Entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on make.fun: write one short funny line answering a prompt — here, the excuse a robot vacuum gives after eating a sock.

## The entry

> "It was on the floor, Your Honor. I rest my case."

48 characters, one line. The joke is a deadpan courtroom defense: the vacuum is on trial for eating a sock, and its whole case is that the sock was on the floor — which is, literally, the vacuum's entire jurisdiction. No setup that overstays, no stock "it looked tasty" excuse.

## How to run

Requires Node 22 (stdlib only, no dependencies):

```sh
node main.ts
```

This writes the entry to `output/entry.txt` (and to `/output/entry.txt` when that directory exists, e.g. in the make.fun harness sandbox). Running it twice produces byte-identical output — the entry is a fixed string, so it is fully deterministic.

## Files

- `main.ts` — the program that writes the entry
- `output/entry.txt` — the generated entry (regenerated by running `node main.ts`)
